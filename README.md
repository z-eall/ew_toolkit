# EW Toolkit

Hub site for QoL tools built around [Jere Kuusela's](https://github.com/JereKuusela) Valheim mods. Starts with a validator, more tools land here over time.

## Tools

- **[EWP Validator](ewp_validator/)** — catches bad keys, wrong types, and typos in Expand World Prefabs (EWP) YAML before you load it in-game, with exact file/line locations and key/type autocomplete.
