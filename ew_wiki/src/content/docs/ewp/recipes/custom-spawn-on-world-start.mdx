A task-oriented recipe: spawn one prefab a single time, right when the world first loads.

<Steps>

1. Pick the prefab to spawn (e.g. `Boar`) and give the rule a `type: spawn`.

2. Add a `data:` key pointing at a WEC data entry that carries the spawn's tuning (amount, radius, etc.) — see [Concepts → Schema](/concepts/schema/) for what `data:` resolves to.

3. Add a start condition so it fires once on world creation rather than every load.

4. Try it below — the playground live-validates against the same schema the EWP validator uses.

</Steps>

	id="recipe-custom-spawn"

  type: spawn

  onStart: true
`}
